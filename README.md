# @kamishnikov_da/page-preview

Веб-компонент `<page-preview>` загружает HTML-страницу и показывает её название,
первый заголовок `h1` и ссылку. Работает в браузере без зависимостей и внешних CDN.

## Установка и подключение

```sh
npm install @kamishnikov_da/page-preview
```

В приложении со сборщиком или настроенной import map:

```js
import '@kamishnikov_da/page-preview';
```

Импорт сам регистрирует элемент. Дополнительный вызов регистрации не нужен.

```html
<page-preview src="/pages/example.html"></page-preview>
```

Без сборщика можно подключить модуль относительным URL, как в `demo/index.html`.
Обычный браузер без import map не разрешает имена npm-пакетов в импортах.

## Интерфейс

- `src`: адрес страницы; относительный URL разрешается относительно `document.baseURI`.
- `data-status`: `loading`, `ready` или `error` на самом компоненте.
- Открытый `shadowRoot` содержит `a[part="link"]`, `span[part="title"]`
  и `span[part="heading"]`.
- При отсутствии названия выводится «Название отсутствует», а заголовка:
  «Заголовок отсутствует». Ссылка без названия содержит URL.
- Изменение `src` запускает новую загрузку, старый ответ игнорируется.
- Удаление отменяет запрос, повторное подключение запускает загрузку снова.

Страница должна быть доступна браузерному fetch: на том же origin или с разрешающими
CORS-заголовками. HTTP-ошибки, сетевые ошибки и отсутствие `src` переводят элемент
в состояние `error`. Полученные значения вставляются как текст, HTML не исполняется.

## Демонстрация

Из корня репозитория запустите любой статический HTTP-сервер, например:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000/demo/`. Первый экземпляр показывает пробную страницу,
второй демонстрирует ошибку 404. Открытие через `file://` не подходит.

## Проверка

```sh
npm install
npx playwright install chromium
npm test
npm pack --dry-run
```

Тесты проверяют регистрацию, Shadow DOM, начальную загрузку, относительные адреса,
пустые значения, HTML-сущности, ошибки, безопасный текст, гонки запросов,
независимые экземпляры, удаление и повторное подключение.
